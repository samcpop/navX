# navX
Pop-out heading navigator for Microsoft Word (plugin, Mac)


INSTRUCTIONS
1. Download [navX.dotm](https://github.com/samcpop/navX/blob/main/navX.dotm)
2. Put it in the following folder
   MAC
   i. Open Finder and Press Cmd + Shift + G
   ii. Enter and select ~/Library/Group Containers/UBF8T30669.Office/User Content/Startup
   iii. Put it in /Word
   WINDOWS: Check for native functionality
   i. Press Win + R to open Run
   ii. Enter %appdata%\Microsoft\Word
   iii. Put it in \STARTUP
4. Restart Word + Select the View tab
5. Click the 'Macros' button, and run 'showHeadings'
